The Two-Surface Machine

A photonic processor encodes data as the amplitude and phase of coherent light, computes by interference through a mesh of couplers and phase-shifters — the whole linear operation resolving in one propagation — and reads results only at measurement, where amplitudes collapse to definite outcomes by the Born rule. Before that moment the machine genuinely holds superposition: every candidate outcome at once, phases live — the thing a classical bit, already definite, cannot do.

This page is that machine as exact, mutation-gated arithmetic — the simulator the build path starts with. Every demo below runs the same kernel CI gates.
